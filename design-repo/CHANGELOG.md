# Changelog

## 1.0.0 (initial build)

Built from scratch against the mirrored production build (`../site`, read-only) and the running
clone server, following BUILD-GUIDE order and BASELINE R1-R16.

### Parity harness fixes (applied after the build agent was stopped)
- `parity.mjs` scroll helper: it now stops when the scroller stops moving. Sections that can never reach the top quarter of the viewport (end of /about) used to burn 4x400 wheel events each, so a two-run journey ran past an hour without finishing. A run now takes about 14 minutes.
- Crops are captured with a 2px margin and compared aligned on each side's own DOM-measured top edge, measured rather than searched. A sub-pixel settle difference on `chapter.body` remains (0.867 in both runs, passes the gate) and is documented in README "Parity".
- `prove_drift.py`: the two "pin removed" cases searched for the signature pin with a trailing space that is not in the files (the pin ends its line), so the script crashed before reporting. Search text corrected; all 55 injections now run and are caught.

### Evidence
- `extraction/extract_evidence.mjs` extended (deterministic; the pre-existing evidence files were
  re-generated byte-identical): adds `markup.txt` (render-function element fragments, line-citeable;
  used for section provenance) and `asset-inventory.json` (mirrored media paths, sizes and sha256, no
  content; grounds asset roles and leakage patterns).
- `extraction/measure_sections.mjs` re-run at 1440/768/390: the selector map moved to
  `extraction/section-selectors.mjs` (shared with `parity.mjs`), shell/runtime sections are now looked
  up on every app route, per-section structure (heading words, paragraph word counts) is recorded, and
  the `/formats/` section is `cta.download-formats` (conversion block, CTA class).
- All evidence files are sha256-pinned in `measured-values.json` (`evidence-pins` check).

### Built
- Tokens (foundation, semantic, component, layout, light theme), token catalog + token policy,

  with every citation resolved by needle.
- 20 section contracts, 6 primitives, 6 components, 6 templates, 17 routes (each mapped once),
  11 compatibility rules, 27 asset roles, closed Draft-07 PageSpec schema (pageSpecVersion 1.0.0 with
  required `mode`), closed section-contract schema, source-identity patterns.
- `schema/semantic_validate.py`, `schema/tests/adversarial_test.py`, `extraction/verify_all.py`,
  `extraction/wrapper_gate.py`, `extraction/policy_hash.py`, `extraction/prove_drift.py`,
  `extraction/parity.mjs`.
- Examples: reference chapter one (real copy) + generated intro, chapter, about, download-formats.

### Decisions recorded from evidence
- About page: "I never set out to be a leader" is the `content.about-book` heading; the stories are
  "I had to leave home to build a better life" and "This is not an all-or-nothing endeavor".
- About closer statistics (16,020 words, 1,039 copies sold, 28 illustrated scenes, 160 pages) are a
  `stat-block` component inside `cta.download-closer` (same `<section>` as the Download button), and
  are generated-mode leakage patterns (`GENERATED_MODE_STATISTIC`).
- `/navigation` is the `chapter-index` template (NAVIGATION, retrievalEligible true), not an overlay.
- Asset leakage patterns are real source file paths, not file formats (a generated `.glb` is fine).
- `GENERATED_MODE_RATING`: not applicable (no reviews/ratings/testimonials in the source; no rating field).
